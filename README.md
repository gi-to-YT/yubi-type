# ゆびタイプ

スマホの指で打つ、日本語のタイピング練習です。ブラウザーで開くだけで遊べます。

**遊ぶ：** https://gi-to-yt.github.io/yubi-type/


見た目のテーマは「ことばのダンジョン」。和紙と墨と朱の「墨と和紙の迷宮」で、打つほど問題文が墨で書き上がり、結果のランクは朱の印で押されます。
## できること

- **キーボードは2種類**（アプリの中のキーボードで打ちます）
  - QWERTY（ローマ字）：shi／si、tsu／tu など、どの打ち方でも正解
  - テンキー：フリックとトグル入力。「小゛゜」キーで濁点・小さい字
  - キーのすき間なし（スマホのキーボード風）にもできます
- **コース**：単語・ことわざ・文章・苦手特訓・じぶんで追加
- **今日のダンジョン**：日付ごとに全員同じ迷宮に潜る
- **今週の縛り**：週ごとに決まりが変わる60秒（ミス3回で終わり、お手本なし、読みがなを隠す など）。週ごとのランキングつき
- **深層**：モンスター戦で地下25階に着くと、決まりが1つずつ厳しくなる深層が開く
- **書き写し**：青空文庫の名作の冒頭を5文ずつ打ち進める。続きから打てて、書き終えると朱の印
- **ルール**：60秒／10問／モンスター戦（地下へ進むローグライク。勝つたびに「ちから」を選び、分かれ道を選ぶ。やられたら最初から）
- **ランキング**：QWERTY・テンキー・PC（本物のキーボードで打った記録）に分けて競う
- **打ち方**：漢字・カタカナに自分で変換する（キーボードの上に候補が出ます）、句読点を打たない
- **記録・称号**：日ごとのベストのグラフ、苦手な字、結果に「ミスした字」と「迷った字」、称号
- **シェア**：結果の文をコピー、X に投稿、結果カードを画像で保存

記録・称号・設定は、遊んでいる端末のブラウザーにだけ保存されます。遊ぶのはすべて無料です。

スマホのホーム画面に追加すると、アプリのように開けて、電波がなくても遊べます（ランキングは、つながったときに送ります）。

## ファイル

`index.html` 1つで動きます（外から読み込むのは、フォントと、ランキング用の Firebase と、広告だけです）。

## 管理用メモ

- ランキングは Firebase（Cloud Firestore）に保存します。書き込みの決まりは `firestore.rules` にあり、Firebase コンソールの Firestore Database →「ルール」に貼って公開します。
- `index.html` の `FIREBASE_CONFIG` に Firebase のウェブアプリの設定を入れると、ランキングが動きます（この値はページに埋め込まれる公開情報で、パスワードではありません）。
